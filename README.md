A production-grade full-stack API key management system.

### Tech Stack
- **Backend**: Java 21, Spring Boot 3, Spring Data JPA, Docker
- **Frontend**: React, TypeScript, Tailwind CSS, Recharts
- **Database**: PostgreSQL (Neon)
- **Deployment**: Render (Backend), Vercel (Frontend)

### Key Features
- Secure SHA-256 API key generation and hashing.
- Scoped permissions (`read`/`write`).
- Custom Spring Security filter for API key authentication.
- Real-time usage analytics and latency charting.
- Production-ready CORS and database configurations.
